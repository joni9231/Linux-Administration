Current server status

Information Value
Report generated $GENERATED_AT
Server uptime $UPTIME_TEXT
Root filesystem disk usage $DISK_USAGE
Disk space status $DISK_STATUS
Total RAM $MEM_TOTAL MiB
Available RAM $MEM_AVAILABLE MiB

Disk space status is OK below 80% usage and WARNING at 80% or above.

Bash generates this report once per minute. Wait approximately 1–2 minutes and reload the page to see a new generation time.

Commands used

  • date: displays the current date, time and time zone using the format specified in the script.
  • uptime -p: displays how long the server has been running.
  • df -P / | awk 'NR == 2 {print $5}': passes filesystem information to awk, which extracts the usage percentage from the second row.
  • free -m: displays memory information in mebibytes (MiB).

How the script works

The script collects server information using Linux commands and stores the results in Bash variables through command substitution. A function uses an if statement to determine the disk space status.

The script generates a temporary HTML file and then moves the completed file into place as index.html. Nginx serves this file at /viikko3/.
